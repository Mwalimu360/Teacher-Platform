ALGEBRA

Form 1 Mathematics

📖 Notes

1. Meaning of Algebra

Algebra is a branch of Mathematics that uses letters, numbers and mathematical symbols to represent quantities and relationships.

2. Variables and Constants

A variable is a letter or symbol whose value can change. A constant is a quantity whose value remains fixed.

Examples of variables are x, y and a. Examples of constants are 5, 10 and 20.

3. Algebraic Expressions

An algebraic expression is a combination of numbers, variables and mathematical operations.

Examples include 3x + 5, 2y - 7 and 4a + 3b.

4. Terms and Coefficients

Terms are parts of an algebraic expression separated by addition or subtraction signs. A coefficient is the numerical factor multiplying a variable.

5. Like Terms

Like terms have the same variables raised to the same powers. Like terms can be combined by adding or subtracting their coefficients.

6. Simplifying Expressions

Algebraic expressions can be simplified by collecting like terms.

💡 Worked Examples

Example 1: Simplify: 3x + 5x

3x + 5x
= (3 + 5)x
= 8x

Example 2: Simplify: 7a + 3 - 2a + 5

Collect like terms:
7a - 2a + 3 + 5
= 5a + 8
Answer = 5a + 8

Example 3: If x = 4, find the value of: 2x + 3

2(4) + 3
= 8 + 3
= 11

✏️ Exercises

  1. Define Algebra.
  2. Identify the variable in 7x + 4.
  3. Simplify 5x + 3x.
  4. Simplify 9a - 4a + 2.
  5. If y = 6, find the value of 3y + 2.
  6. State whether 4x and 7x are like terms.

✅ Answers

1. Algebra is a branch of Mathematics that uses letters, numbers and symbols to represent quantities and relationships.

2. The variable is x.

3. 5x + 3x = 8x

4. 9a - 4a + 2 = 5a + 2

5. 3(6) + 2 = 18 + 2
= 20

6. Yes. 4x and 7x are like terms.
