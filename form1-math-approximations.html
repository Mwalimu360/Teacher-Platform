APPROXIMATIONS

Form 1 Mathematics

📖 Notes

Meaning of Approximation

Approximation is the process of finding a value that is close to an exact value. It is useful when an exact value is not necessary or when a value needs to be expressed in a simpler form.

Rounding Off

Rounding off is a method of approximation in which a number is changed to a nearby value according to a specified place value.

Rounding to the Nearest Whole Number

If the first decimal digit is 5 or greater, the whole number is increased by one. If it is less than 5, the whole number remains unchanged.

Decimal Places

A number can be rounded to a specified number of decimal places such as 1, 2 or 3 decimal places.

Significant Figures

Significant figures are the digits in a number that carry meaningful information about its precision.

💡 Worked Examples

Example 1: Round 47.6 to the nearest whole number.

The decimal digit is 6.
Since 6 is greater than 5, increase 47 by 1.
Answer = 48

Example 2: Round 12.347 to 2 decimal places.

The second decimal digit is 4.
The next digit is 7, which is greater than 5.
Therefore, 4 becomes 5.
Answer = 12.35

Example 3: Round 5832 to the nearest hundred.

The tens digit is 3.
Since 3 is less than 5, the hundreds digit remains unchanged.
Answer = 5800
